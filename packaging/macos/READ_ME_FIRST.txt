ATK Player for macOS
====================

Install: drag ATK Player onto the Applications folder.

This build is not yet signed with an Apple Developer ID or notarised by Apple,
the same way the Windows installer is not yet code-signed. macOS will say it
"cannot verify" ATK Player the first time you open it. To open it anyway:

  1. In Applications, Control-click (or right-click) ATK Player and choose Open.
  2. Click Open in the dialog that follows.

On recent macOS versions, if there is no Open button: try to open ATK Player
once, then go to System Settings > Privacy & Security, scroll down to the
message about ATK Player and click Open Anyway.

You only need to do this once. Licences for ATK Player, Qt, FFmpeg and zlib are
inside the app: Control-click it, choose Show Package Contents, then open
Contents/Resources/licenses.
