FFmpeg 9.0.1 (vcpkg port revision 1)
------------------------------------
ATK Player dynamically links FFmpeg libraries (libavcodec, libavformat,
libavutil, libswresample, libswscale) built by vcpkg under the GNU Lesser
General Public License, version 2.1 or later (FFmpeg-LGPL-2.1.txt). The build
disables GPL and nonfree components and does not enable x264, x265 or fdk-aac.
The dylibs remain separate, replaceable files in
ATKPlayer.app/Contents/Frameworks. The bundle does not include the ffmpeg or
ffprobe command-line tools, and Qt's own FFmpeg media plugin is removed.
Project and source: https://ffmpeg.org/ and https://ffmpeg.org/download.html
Build source: https://github.com/microsoft/vcpkg/tree/45f9f39362a4c52e2b1fbe57b7e649db7f3d96d4/ports/ffmpeg
with the triplets in cmake/triplets of the ATK Player source (dynamic
libraries, macOS 12 minimum).
Component notices and configuration: dependencies/FFmpeg-NOTICES.txt and
dependencies/FFmpeg-BUILD-CONFIGURATION.json. Corresponding patched source and
the complete pinned vcpkg port/build source are included in dependencies/sources.

Source archives and notice scope
--------------------------------
Source-only archives omit unrelated prebuilt binaries, unused font fixtures and
test signing material; every exclusion is listed in
dependencies/SOURCE-EXCLUSIONS.json. No application runtime file is removed.
Complete upstream source-wide notices can describe build tools, tests and
unselected GPL code; this does not enable those components or change the
configured Qt/FFmpeg runtime licenses.
