# ATK Player 0.2.0

First public Windows release.

## Highlights

- Frame-accurate video playback with synchronized audio
- Animation-focused timeline, typed frame navigation and active review ranges
- Bookmarks, notes and waveform display
- A/B comparison with side-by-side, stacked, wipe, blend and difference modes
- Projects and playlists
- MP4 review and image-sequence/single-frame export with optional burn-ins
- Media Information
- Local API and Python client
- Maya integration
- Toon Boom Harmony integration

## Requirements

- Windows 11 x64 (the currently verified release platform)
- Microsoft Visual C++ 2015-2022 x64 Redistributable

ATK Player is open-source software under the MIT License. Source and license
information: https://github.com/dshepstone/ATK_Player

The `0.2.0-rc1` installer is an unsigned acceptance build. Windows SmartScreen
may display a warning; verify the published SHA-256 checksum before installing.
